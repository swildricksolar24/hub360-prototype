# Design tokens

Every token below is read from `design-system/tokens/tokens.json`, which is generated from the
[Figma design system](https://www.figma.com/design/ieTXU4rFsUAmlEsF93zF5T/__Design-System---Base).
Use them as CSS custom properties from `design-system/tokens/tokens.css`. The rules for using them are in `src/design-system.md`.

Swatches show both Figma modes, whichever theme the toolbar is set to.
Switch **Theme** in the toolbar to see the components in dark mode.

## Color: semantic

[Open the Colors page in Figma](https://www.figma.com/design/ieTXU4rFsUAmlEsF93zF5T/__Design-System---Base?node-id=3-229) ·
